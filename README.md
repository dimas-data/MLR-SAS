MLR for Chance of Admittance
============================

This project is a SAS-coded multiple linear regression (MLR) model, for building a relationship model between independent variables (GRE Score, TOEFL Score, University Rating, SOP, LOR, GPA, Research) and dependent variable (chance of admit). The model can be used in a variety of use cases, from initial feature assessment (determining which factors like GPA or GRE scores have the largest linear impact), and predictive scoring tool creation.

Testing and Validation
----------------------

The model doesn't have extensive test coverage, and has not been validated through extensive use in real-life scenarios.

Data Source & Acknowledgements
------------------------------

The primary data used for the predictive model in this project is the "Graduate Admission Dataset" (Bangladeshi perspective), sourced from the Kaggle platform.
